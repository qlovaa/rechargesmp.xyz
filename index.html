What happens when I lose all three lives?+

You’ll be able to rejoin when your next life recharges. A missing life recharges every eight hours, up to three lives.

Can I use the same server address every time?+

Yes. Save rechargesmp.xyz in your Minecraft Java multiplayer list so you can find it again easily.

How often does the live player count update?+

The website checks server status every 60 seconds while this page is open. The status provider may briefly cache the results. If the lookup fails, we show that clearly instead of inventing a count.
